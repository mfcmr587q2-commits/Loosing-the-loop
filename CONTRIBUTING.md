# Contributing

Contributions should make the architecture more testable, falsifiable, and auditable.

## Good contributions

- executable tests;
- threat-model improvements;
- formal definitions;
- provenance and audit mechanisms;
- reproducible experiments;
- clear counterexamples;
- documentation that distinguishes hypotheses from validated results.

## Evidence standard

Do not present an untested design claim as an established security property. Include assumptions, test conditions, observed results, and known limitations.
